**Personal Portfolio Website**

This repository contains the source code for my professional portfolio website. It serves as a central hub to showcase my technical skills, personal projects, and professional journey as a developer.

[![Vercel](https://img.shields.io/badge/Live_Demo-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://nisith-portfolio.vercel.app/)

**🚀 Overview**

The goal of this project was to create a fast, responsive, and modern portfolio that reflects my focus on clean UI/UX and efficient frontend code. It highlights my expertise in building interactive web experiences and managing end-to-end development.

**🛠️ Tech Stack**

Frontend: Next.js with TypeSccript

Styling: Tailwind CSS 

Deployment: Vercel (CI/CD integrated with GitHub)

Tools: NPM, Git, VS Code

**✨ Key Features**

Responsive Design: Fully optimized for mobile, tablet, and desktop screens.

Project Showcase: A curated gallery of my work with links to live demos and source code.

Interactive Elements: Smooth navigation and interactive UI components built with JavaScript.

Contact Integration: A dedicated section for professional inquiries and social links.
